Install Guide

If you bought a device from us, this is already done — it comes preinstalled and set up, just log in with the username and password you were given at purchase. If you're installing on your own device, follow the steps below.

How to use Unlinked

Install Downloader

If you don't already have Downloader, search for it in your device's app store and install it.

Install Unlinked

Open Downloader and enter code 234753, then download and install Unlinked.

Open the library

Open Unlinked and enter the library key 🔑 B46DA2E8.

Install Austreams Hub

Find and install Austreams Hub from the library, then log in with your username and password.
